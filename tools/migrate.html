Správa dat

Záloha, import a přemapování starých tipů. Jen pro správce.

Záloha

Stáhne všechny čtyři kolekce do jednoho JSON souboru.

Import

Vlož obsah zálohy. Dokumenty se stejným id se přepíšou, nové přibudou.

Přemapovat legacy tip

Přenese tipy ze starého dokumentu pod účet existujícího hráče. Starý dokument se pak smaže.

Smazat hráče

Smaže dokument hráče v tips i s jeho tipy. Zadej přezdívku nebo uid.
